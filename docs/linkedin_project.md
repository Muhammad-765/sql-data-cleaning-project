## LinkedIn Project Description

Cleaned and transformed a real-world layoffs dataset using MySQL, building an end-to-end SQL data-cleaning workflow from raw data to an analysis-ready dataset.

Key work included identifying and removing duplicate records, standardizing inconsistent company, industry, and country values, converting text-based dates into proper SQL date values, handling missing and blank industry data using self-joins, and removing records with insufficient layoff information.

The project demonstrates practical experience with MySQL, CTEs, window functions, ROW_NUMBER(), PARTITION BY, JOINs, NULL handling, data standardization, and data-quality validation.

## LinkedIn Launch Post

I’m excited to share my latest data analytics project: **SQL Data Cleaning & Transformation**.

For this project, I worked with a real-world layoffs dataset and built an end-to-end cleaning workflow in MySQL.

The project involved:

• Creating staging tables to protect the raw data  
• Detecting and removing duplicate records using ROW_NUMBER() and PARTITION BY  
• Standardizing inconsistent text values  
• Converting text-based dates into proper SQL DATE values  
• Handling NULL and blank values  
• Using self-JOINs to populate missing industry information where possible  
• Removing records without meaningful layoff information  

The final cleaned dataset went from **2,361 raw records to 1,995 analysis-ready records** after duplicate and unusable-record removal.

This project helped me strengthen my practical SQL skills and understand how important data quality is before analysis begins.
